# Security

Please report suspected vulnerabilities privately, using GitHub's
[private vulnerability reporting](https://github.com/prayantr/clicksend/security/advisories/new)
for this repository. Do not open a public issue.

Never include ClickSend API keys, phone numbers or message contents in a report. If a key
may have been exposed, regenerate it in the ClickSend dashboard.

This gem is not affiliated with ClickSend. Report vulnerabilities in ClickSend's own
service to ClickSend.
